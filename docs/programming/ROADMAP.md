# Court6 program roadmap: six cycles

**Six 9-week cycles, starting Mon Oct 19, 2026**
Every cycle: test · build · retest · one new skill
Every workout comes in 3 levels: Steady, Strong, Full

The program runs in six 9-week cycles. Each cycle starts with a test, builds for six weeks, then retests so you can see your progress. Each cycle teaches one skill, and your retest numbers carry into the next cycle.

## Inside every cycle (9 weeks)

| Week | Phase | What happens |
|---|---|---|
| 1 | Test | Test your lifts and your run (or row). They set your weights and paces. |
| 2 | Base | Skill baseline: your starting point on the skill. |
| 3–4 | Base | Moderate weights, steady volume, weekly skill practice. |
| 5–6 | Build | Heavier weights, fewer reps; the skill steps up. |
| 7 | Primer | Deload: less volume, so you're fresh to test. |
| 8 | Retest | Week 1 tests again, same days: see your progress. |
| 9 | Flex | Skill retest + benchmarks. Results start the next cycle. |

## Benchmark workouts in plain words

Full loads are written lighter/heavier, in pounds. Every level scales.

| Name | The workout |
|---|---|
| Cindy | 20 minutes, as many rounds as possible: 5 pull-ups, 10 push-ups, 15 air squats. |
| Helen | 3 rounds for time: 400 m run, 21 kettlebell swings (35/53 lb), 12 pull-ups. |
| Fran | 21-15-9 reps for time: thrusters (65/95 lb) and pull-ups. |
| Grace | 30 clean & jerks for time (95/135 lb). |
| Diane | 21-15-9 reps for time: deadlifts (155/225 lb) and handstand push-ups. |
| Isabel | 30 snatches for time (95/135 lb). |
| Station test | 10 minutes, as many rounds as possible: wall balls, farmers carry, sandbag lunges, burpee broad jumps. |
| Court6 Mini Challenge | Our short challenge: 4 short runs, each into a station: row, burpee broad jumps, sandbag lunges, wall balls. |
| Court6 Challenge (half / full) | Runs into stations: 1 km run, then 1 station, 4 times (half) or 8 times (full), using the stations we have. |

Cycles run back to back, Monday to Sunday; classes are on weekdays. Holiday weeks run on holiday hours if needed.
